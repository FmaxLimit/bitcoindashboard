Momentum Backtest
Historical win rate of one simple rule, on data already buffered
Set a Start clock time to anchor the very first round. Pick and End are durations, not clock times - e.g. Pick = 5 min, End = 10 min means: check the price 5 minutes after Start (the "Pick" checkpoint), then again 10 minutes after Start (the "End" checkpoint). Once that round finishes, the next round's Start is automatically that round's End - it keeps chaining forward through every bit of buffered live history, back to back, with no gaps. Then it checks each round: did the price move the same direction from Start→Pick as it then did from Pick→End? That's a "win" for the momentum rule. It's a backtest of the past, not a bet, and it doesn't use or track any money.
